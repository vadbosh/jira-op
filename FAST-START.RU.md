# Быстрый старт

Один экран. Полное руководство: [docs/setup.ru.md](docs/setup.ru.md) ·
[in English](FAST-START.md)

## Один раз

```bash
umask 077; read -r -s -p 'token: ' T \
  && printf 'JIRA_API_TOKEN=%s\n' "$T" > ~/.config/.jira/token.env && unset T
set -a; . ~/.config/.jira/token.env; set +a
jira init          # Cloud, адрес сайта, login email, ключ проекта, доска
./install.sh       # скил во все ассистенты; заодно считает id полей проекта
jira me            # печатает ваш login — значит работает

SKILL=~/.claude/skills/jira-op   # либо ~/.codex/… либо ~/.config/opencode/skills/…
```

Токен идёт первым: `jira init` аутентифицируется по ходу своих вопросов.

## Дальше просто говорите ассистенту

| Вы говорите | Что происходит |
|---|---|
| `покажи мои открытые задачи` | список, и всё |
| `что в активном спринте` | тот спринт, в который попадает сегодня |
| `разбери PROJ-123` | только чтение: факты, гипотезы, что проверить не удалось |
| `заведи таску: <что сделал>` | сначала черновик — без вашего «да» ничего не создаётся |
| `сделай недельный отчёт` | пишет `.txt` в каталог проекта, в ответ — путь |

## Заведение задачи

Три вопроса: **story points**, **какой спринт**, **End Date** («не надо» —
нормальный ответ). Дальше черновик печатается целиком — описание, риски,
критерии приёмки — и ничего не создаётся, пока вы не одобрите. Черновик на
английском, каким бы языком вы ни спрашивали; summary остаётся общим, а
количества и версии живут в теле.

Эпик не проставляется — привяжете в интерфейсе. **Созданную задачу откатить
нельзя** на большинстве аккаунтов, поэтому пробных тикетов не бывает.

## Недельный отчёт

Календарная неделя, с понедельника 00:00 по воскресенье 23:59; запускать
вечером пятницы или утром субботы. Спросят, не попал ли в окно отпуск. Работы в
выходные относятся к той же неделе — если отчёт ещё не отправлен, пересоберите
файл.

Отчёт пишется обычным текстом в каталог проекта, в ответ приходит только путь:
содержимое в переписку не выводится, существующий файл не перезаписывается
(второй запуск создаст `-2`).

```
weekly-update-2026-08-31_2026-09-06.txt
```

Как он выглядит: [docs/example-weekly-update.txt](docs/example-weekly-update.txt).
В отчёте только факты работы — ни возраста задач, ни переносов между спринтами,
ни пустых полей, — а незапущенные задачи не появляются вовсе. Два предложения на
пункт, без перечней компонентов и версий. Задача, которая тянется месяцами,
приходит каждую неделю дельтой, прочитанной из её changelog.

## Несколько сайтов Jira

```bash
$SKILL/scripts/add-site.sh acme     # спросит токен, запустит init, создаст SITE.acme.md
. $SKILL/scripts/jira_site.sh       # эту строку в ~/.bashrc
jira_site acme                      # переключиться   jira_site default — обратно
```

## Если что-то сломалось

```bash
jira me                                     # 401 — не тот токен или не тот email
$SKILL/scripts/site-probe.sh --all --check  # в проекте поменяли поля или статусы
```

Создание падает на незнакомом `customfield_*` — схему поменяли: запустите
`--write` и повторите.
